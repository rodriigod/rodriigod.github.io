# Rodrigo Jorquera Díaz — Portfolio

Portfolio personal simple, hecho solamente con HTML + CSS.

## Archivos

- `index.html` — contenido de la página.
- `style.css` — diseño.
- `profile.jpg` — agrega aquí tu foto.

## Para personalizar

1. Pon tu foto en esta carpeta con el nombre `profile.jpg`.
2. Abre `index.html` en el navegador.
3. Cambia los textos de `index.html`.
4. Reemplaza los enlaces que están como `#` por los enlaces reales de tus proyectos.
5. Para agregar un proyecto, copia un bloque `<article class="project">...</article>`.

No usa JavaScript ni carga automáticamente Medium.
